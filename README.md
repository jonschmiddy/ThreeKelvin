# Three Kelvin builds

Alpha builds for playtesters, one folder per version. Windows: the `win64` zip. Mac: the `mac` zip.
Each zip has README-ALPHA.txt inside with how to open it the first time.

To download on GitHub: open the zip's file, then press the download button (Download raw file).
