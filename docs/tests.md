# Which test to run

One row per harness, moved here from `tkg/CLAUDE.md` so it is read when a test is
being chosen rather than loaded into every session. Find the rows that name what you
touched (`grep -n <ClassName> docs/tests.md`) and run each. **In the merge gate** means
`.github/scripts/validate.sh` runs it too. A new harness adds its row here.
