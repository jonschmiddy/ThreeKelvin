## Which part takes which group

Tune, Middle melody, Echo, Chords and Extra take any melodic instrument (groups above except Bass and Drum kits).
Bass takes a bass instrument. Drums takes a kit. The lab enforces this, so a palette can never be set to something that cannot play the part.
